Drei KinoDonnerstag in Wien: So bekommst du zwei Kinotickets zum Preis von einem.

Mit einem berechtigten Drei Handyvertrag erhältst du bei teilnehmenden Cineplexx- und Constantin-Film-Kinos jeden Donnerstag zwei Tickets zum Preis von einem.

Der Drei KinoDonnerstag in Wien ist ein 1+1-Vorteil für berechtigte Drei Kund:innen: An jedem Donnerstag gibt es bei teilnehmenden Cineplexx- und Constantin-Film-Kinos zwei Tickets zum Preis von einem. Der Rabatt wird nicht beim Onlinekauf abgezogen, sondern mit einem SMS-Code an der Kinokassa eingelöst.

Wichtig zur LaufzeitDrei führt den Vorteil „bis auf Widerruf“. Die Aktion hat damit kein veröffentlichtes festes Enddatum. Prüfe die offizielle Drei-Seite zum KinoDonnerstag direkt vor der Reservierung erneut.

So funktioniert der KinoDonnerstag

  1. Sende eine kostenlose SMS mit Kino an 2121.
  2. Warte auf den Code per SMS.
  3. Reserviere bei Bedarf Tickets für eine Donnerstagsvorstellung in einem teilnehmenden Kino. Laut Drei ist die Reservierung ab einem Tag vorher möglich; nur reservieren, nicht online kaufen.
  4. Zeige den Code beim Bezahlen an der Kinokassa vor. Dort werden zwei Tickets zum Preis von einem verrechnet.

Wer den Deal nutzen kann

Nach der offiziellen Drei-Information gilt der Vorteil für Kund:innen mit einem Drei Handyvertrag. Nicht berechtigt sind up-Abo, Wertkarte und Internet-Tarife. Der Code ist nicht übertragbar und pro Person kann an einem KinoDonnerstag nur ein Code eingelöst werden.

Aufpreise und Ausnahmen vorab prüfen

„Zwei zum Preis von einem“ bedeutet nicht zwingend zwei identische Endpreise. Drei schließt Sondervorstellungen, Suiten und MX4D aus. Für Überlänge, 3D, IMAX, Dolby Cinema, Onyx Cinema LED, Real D Ultimate Screen sowie Cinegold und Supreme nennt Drei Aufpreise. Auch für das zweite Ticket kann an der Kassa ein Zuschlag anfallen. Frag im Zweifel vor der Reservierung im gewünschten Kino nach dem Endpreis für genau deine Vorstellung.

Für einen Kinoabend in Wien planen

Öffne zuerst die aktuelle Drei-Bedingungsseite und prüfe anschließend, ob dein gewünschtes Wiener Kino teilnimmt. Wenn du reservierst, wähle eine Donnerstagsvorstellung und bezahle erst an der Kassa mit dem SMS-Code. So vermeidest du, dass der Vorteil bei einem vorab gekauften Onlineticket nicht angewendet werden kann.

Fazit

Der Drei KinoDonnerstag ist ein transparenter 1+1-Vorteil für einen regulären Kinobesuch in Wien, aber nur mit berechtigtem Drei Handyvertrag, SMS-Code und Beachtung der Aufpreise. Weil Drei kein festes Ablaufdatum veröffentlicht, bleibt der Beitrag bewusst als laufendes Angebot gekennzeichnet.
